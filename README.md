# Gielinor: Cardbound

Mobile-first OSRS-inspired collectible progression game prototype.

The playable build is served directly from `index.html` and stores progress locally in the browser.

## Current MVP
- Tiered card packs and rarity rolls
- Equipment, monsters, bosses and skilling unlocks
- Bank/loadout system
- Combat, Woodcutting, Mining and Fishing point generation
- Duplicate shredding and fragment crafting
- Mobile-first UI and local save data

> Fan prototype. Review Jagex fan-content/licensing requirements before public distribution or monetization using Jagex intellectual property.
